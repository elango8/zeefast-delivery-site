# ZeeFast Project - Setup & Run Guide
# =====================================

## Project Overview
ZeeFast is a food delivery web application with:
- Frontend: Static HTML/CSS/JS files
- Backend: Node.js/Express API server

## Project Structure
```
D:\project1\
├── frontend\              # Frontend files (HTML, CSS, JS)
│   ├── index.html         # Home page
│   ├── restaurants.html   # Restaurant listing
│   ├── menu.html          # Restaurant menu page
│   ├── cart.html          # Shopping cart
│   ├── login.html         # Login/Register
│   ├── profile.html       # User profile
│   ├── orders.html        # Order history
│   ├── payment.html       # Payment page
│   ├── contactus.html     # Contact page
│   ├── recommendations.html # Services page
│   ├── css\               # Stylesheets
│   ├── js\                # JavaScript files
│   └── images\            # Image assets
│
└── backend\               # Backend API server
    ├── server.js          # Main server file
    ├── package.json       # Node.js dependencies
    ├── controllers\       # API controllers
    ├── routes\            # API routes
    └── data\              # JSON data files
        └── restaurants.json  # Restaurant data
```

=====================================
## HOW TO RUN THE PROJECT
=====================================

### STEP 1: Install Node.js (if not installed)
Download and install Node.js from: https://nodejs.org/

### STEP 2: Open Terminal/Command Prompt
Open PowerShell or Command Prompt

### STEP 3: Start Backend Server
```
cd D:\project1\backend
npm install          # (only first time)
npm start
```
Backend will run at: http://localhost:3000

### STEP 4: Start Frontend Server (New Terminal)
Open a NEW terminal window and run:
```
cd D:\project1\frontend
npx -y live-server --port=8080
```
Frontend will run at: http://localhost:8080
(Browser will open automatically)

NOTE: If port 8080 is busy, live-server will use another port.
Check the terminal output for the actual URL like:
"Serving at http://127.0.0.1:54260"

### STEP 5: Open in Browser
Navigate to: http://localhost:8080

=====================================
## TROUBLESHOOTING
=====================================

### Port Already in Use
If port 8080 is busy, use a different port:
```
npx -y live-server --port=3001
```

### Backend Not Starting
1. Make sure you're in the backend folder
2. Run: npm install
3. Then run: npm start

### Changes Not Reflecting
- With live-server, changes auto-refresh
- If not, clear browser cache (Ctrl+Shift+R)

### 404 Error on Menu Page
Make sure to use .html extension:
- CORRECT: menu.html?id=1
- WRONG: menu?id=1

=====================================
## STOPPING THE SERVERS
=====================================

1. Go to the terminal running the server
2. Press Ctrl+C to stop it
3. Repeat for both backend and frontend terminals

=====================================
## TIPS
=====================================

1. Always start BACKEND first, then FRONTEND
2. Use live-server for auto-refresh on file changes
3. Check browser console (F12) for any errors
4. Restaurant data is in: backend\data\restaurants.json
5. Mock data for frontend: frontend\js\mockData.js
